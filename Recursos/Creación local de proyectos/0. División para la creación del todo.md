# La creación del todo, pero sin hacer un archivo de 4.000 líneas

[[README|Volver al mundo conocido]]

Vamos a construir una discoteca. Por ahora no tenemos luces, bebidas ni una base de datos; tenemos una carpeta y bastante fe. Para que el proyecto no termine siendo un `final_final_ahora_si_funciona.zip`, este es el orden de la ceremonia:

1. [[Recursos/Stack y entorno|Crear la aplicación]] — Primero los cimientos. El nombre épico del proyecto puede esperar cinco minutos.
2. [[Semana1/CLASE 3|Levantar PostgreSQL con Docker]] — Darles un hogar a los datos antes de dejarlos viviendo en un array.
3. [[Semana1/CLASE 4|Conectar Prisma y preparar las migraciones]] — Presentarle la aplicación a la base de datos. Ojalá se caigan bien.
4. [[Semana1/CLASE 5|Construir la primera funcionalidad]] — Una ruta que responde ya cuenta como progreso; todavía no hace falta contratar un DJ.
5. [[Semana1/CLASE 1|Trabajar con Git y organizarse en Obsidian]] — Guardar la historia del código y conectar los apuntes para no depender de «creo que eso estaba en algún lado».

> [!tip] Cada cosa en su universo
> Los comandos van en el repositorio de la aplicación. Esta bóveda es el mapa; ejecutar instalaciones aquí sería como montar la barra dentro del manual de instrucciones.

La arquitectura sigue siendo vertical: cada funcionalidad reúne sus datos, backend y frontend. Las únicas capas que queremos improvisar son las de ropa para salir de la discoteca a las tres de la mañana.
