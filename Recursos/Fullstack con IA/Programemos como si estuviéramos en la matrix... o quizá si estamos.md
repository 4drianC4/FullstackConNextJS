# Fullstack con IA: copiloto sí, piloto automático de la discoteca todavía no

[[README|Inicio]] · [[semana4/CLASE 18|Clase 18: planificar e implementar]] · [[semana4/CLASE 19|Clase 19: depurar y revisar]]

Las dos clases contienen instalación, conexión, prompts, prácticas y evaluación. La idea es trabajar con ayuda de IA, no mirar una cascada de código y asentir con la esperanza de que alguien haya entendido algo. Ese alguien también debes ser tú.

OpenCode es la herramienta; NVIDIA es el proveedor de inferencia. Uno organiza el trabajo con el repositorio y el otro proporciona acceso al modelo. No hace falta invitar a OpenAI a esta fiesta.

El curso usa el acceso sin pago disponible para la práctica; el instructor comprueba cuotas y modelo antes de impartirla. «Gratis» no significa «pregúntale por cada punto y coma hasta el amanecer»: no se garantiza inferencia ilimitada ni se exige tarjeta.

Si no hay acceso, usamos la revisión en parejas de la clase 19. El compañero no necesita una API key, aunque sí agradece que expliques el problema antes de entregarle 600 líneas.

> [!tip] El modelo propone; tu diff responde
> Revisa los cambios, comprueba los permisos y ejecuta las pruebas. Si la IA arregla un error borrando la validación, no resolvió el problema: echó al portero para que dejara de rechazar entradas.
